v0.0.0+GITEA-API-APP-VERSION
Base URL
/GITEA-API-APP-SUBURL/api/v1

This documentation describes the Gitea API.

Authentication

AccessTokenapiKey

This authentication option is deprecated for removal in Gitea 1.23. Please use AuthorizationHeaderToken instead.

API Key: access_token in query

AuthorizationHeaderTokenapiKey

API tokens must be prepended with "token" followed by a space.

API Key: Authorization in header

BasicAuthhttp

Scheme: basic

SudoHeaderapiKey

Sudo API request as the user provided as the key. Admin privileges are required.

API Key: Sudo in header

SudoParamapiKey

Sudo API request as the user provided as the key. Admin privileges are required.

API Key: sudo in query

TOTPHeaderapiKey

Must be used in combination with BasicAuth if two-factor authentication is enabled.

API Key: X-GITEA-OTP in header

TokenapiKey

This authentication option is deprecated for removal in Gitea 1.23. Please use AuthorizationHeaderToken instead.

API Key: token in query
