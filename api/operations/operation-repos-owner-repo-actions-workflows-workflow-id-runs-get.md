# List runs for a workflow

`GET /repos/{owner}/{repo}/actions/workflows/{workflow_id}/runs`

Authentication (security requirement alternatives):

```json
[
  {
    "BasicAuth": []
  },
  {
    "Token": []
  },
  {
    "AccessToken": []
  },
  {
    "AuthorizationHeaderToken": []
  },
  {
    "SudoParam": []
  },
  {
    "SudoHeader": []
  },
  {
    "TOTPHeader": []
  }
]
```

- BasicAuth: http (basic)
- Token: apiKey, query token. This authentication option is deprecated for removal in Gitea 1.23. Please use AuthorizationHeaderToken instead.
- AccessToken: apiKey, query access_token. This authentication option is deprecated for removal in Gitea 1.23. Please use AuthorizationHeaderToken instead.
- AuthorizationHeaderToken: apiKey, header Authorization. API tokens must be prepended with "token" followed by a space.
- SudoParam: apiKey, query sudo. Sudo API request as the user provided as the key. Admin privileges are required.
- SudoHeader: apiKey, header Sudo. Sudo API request as the user provided as the key. Admin privileges are required.
- TOTPHeader: apiKey, header X-GITEA-OTP. Must be used in combination with BasicAuth if two-factor authentication is enabled.

Parameters:

- `owner` (path, string, required) - owner of the repo
  Type: string

- `repo` (path, string, required) - name of the repo
  Type: string

- `workflow_id` (path, string, required) - id of the workflow, must be the workflow file name (e.g. `build.yml`)
  Type: string

- `event` (query, string, optional) - workflow event name
  Type: string

- `branch` (query, string, optional) - workflow branch
  Type: string

- `status` (query, string, optional) - workflow status (requested, pending, queued, in_progress, failure, success, skipped)
  Type: string

- `actor` (query, string, optional) - triggered by user
  Type: string

- `head_sha` (query, string, optional) - triggering sha of the workflow run
  Type: string

- `exclude_pull_requests` (query, boolean, optional) - if true, the `pull_requests` field on each returned run is emptied
  Type: boolean

- `scoped_workflow_source_repo_id` (query, integer, int64, optional) - For a scoped workflow, the ID of the source repository providing it; omit or 0 for a repo-level workflow.
  Type: integer, int64

- `page` (query, integer, optional) - page number of results to return (1-based)
  Type: integer

- `limit` (query, integer, optional) - page size of results
  Type: integer

Responses:

- 200: 

- 400: APIError is error format response

- 403: APIForbiddenError is a forbidden error response

- 404: APINotFound is a not found empty response
