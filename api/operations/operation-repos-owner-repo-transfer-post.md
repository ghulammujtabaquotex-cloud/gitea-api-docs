# Transfer a repo ownership

`POST /repos/{owner}/{repo}/transfer`

Authentication (security requirement alternatives):

```json
[
  {
    "BasicAuth": []
  },
  {
    "Token": []
  },
  {
    "AccessToken": []
  },
  {
    "AuthorizationHeaderToken": []
  },
  {
    "SudoParam": []
  },
  {
    "SudoHeader": []
  },
  {
    "TOTPHeader": []
  }
]
```

- BasicAuth: http (basic)
- Token: apiKey, query token. This authentication option is deprecated for removal in Gitea 1.23. Please use AuthorizationHeaderToken instead.
- AccessToken: apiKey, query access_token. This authentication option is deprecated for removal in Gitea 1.23. Please use AuthorizationHeaderToken instead.
- AuthorizationHeaderToken: apiKey, header Authorization. API tokens must be prepended with "token" followed by a space.
- SudoParam: apiKey, query sudo. Sudo API request as the user provided as the key. Admin privileges are required.
- SudoHeader: apiKey, header Sudo. Sudo API request as the user provided as the key. Admin privileges are required.
- TOTPHeader: apiKey, header X-GITEA-OTP. Must be used in combination with BasicAuth if two-factor authentication is enabled.

Parameters:

- `owner` (path, string, required) - owner of the repo to transfer
  Type: string

- `repo` (path, string, required) - name of the repo to transfer
  Type: string

Request body: application/json (required)

Transfer Options

Type: TransferRepoOption

TransferRepoOption options when transfer a repository's ownership

Schema: [TransferRepoOption](https://ghulammujtabaquotex-cloud.github.io/gitea-api-docs/api/models/transferrepooption.md)

- `new_owner` (required)
  Type: string

- `team_ids` (optional)
  Type: Array<integer>
  
  ID of the team or teams to add to the repository. Teams can only be added to organization-owned repositories.
  
  Items:
    Type: integer, int64

Responses:

- 202: 

- 403: APIForbiddenError is a forbidden error response

- 404: APINotFound is a not found empty response

- 422: APIValidationError is error format response related to input validation

## Examples

### cURL

```bash
curl -X POST 'https://ghulammujtabaquotex-cloud.github.io/GITEA-API-APP-SUBURL/api/v1/repos/string/string/transfer' \
  -H 'Authorization: Basic WU9VUl9VU0VSTkFNRTpZT1VSX1BBU1NXT1JE' \
  -H 'Content-Type: application/json' \
  --data-raw '{
  "new_owner": "string",
  "team_ids": [
    0
  ]
}'
```

### Python

```python
import requests

  "new_owner": "string",

  ]
}'''
```
