Request Body
Copy
{
  "description": "string",
  "name": "string",
  "value": "string"
}

Body

application/json

UpdateVariableOption the option when updating variable

descriptionstring

Description of the variable to update

namestring

New name for the variable. If the field is empty, the variable name won't be updated.

valuestringrequired

Value of the variable to update

Parameters

orgstringrequiredpath

name of the organization

variablenamestringrequiredpath

name of the variable

Response

201Created

response when updating an org-level variable

204No Content

response when updating an org-level variable

400Bad Request

APIError is error format response

Response headers
messagestringheader
urlstringheader
404Not Found

APINotFound is a not found empty response

Authorization

BasicAuthhttp (basic)
TokenapiKey in query

This authentication option is deprecated for removal in Gitea 1.23. Please use AuthorizationHeaderToken instead.

AccessTokenapiKey in query

This authentication option is deprecated for removal in Gitea 1.23. Please use AuthorizationHeaderToken instead.

AuthorizationHeaderTokenapiKey in header

API tokens must be prepended with "token" followed by a space.

SudoParamapiKey in query

Sudo API request as the user provided as the key. Admin privileges are required.

SudoHeaderapiKey in header

Sudo API request as the user provided as the key. Admin privileges are required.

TOTPHeaderapiKey in header

Must be used in combination with BasicAuth if two-factor authentication is enabled.
