Add an issue to a project column

POST
https://ghulammujtabaquotex-cloud.github.io/GITEA-API-APP-SUBURL/api/v1/user/projects/{id}/columns/{column_id}/issues/{issue_id}

Assigns the issue to the project if it is not a member yet, then places it in the column.

curl -X POST 'https://ghulammujtabaquotex-cloud.github.io/GITEA-API-APP-SUBURL/api/v1/user/projects/0/columns/0/issues/0' \
  -H 'Authorization: Basic WU9VUl9VU0VSTkFNRTpZT1VSX1BBU1NXT1JE'
