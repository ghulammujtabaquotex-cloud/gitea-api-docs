# AnnotatedTagObject

Type: AnnotatedTagObject

AnnotatedTagObject contains meta information of the tag object

Schema: [AnnotatedTagObject](https://ghulammujtabaquotex-cloud.github.io/gitea-api-docs/api/models/annotatedtagobject.md)

- `sha` (optional)
  Type: string
  
  The SHA hash of the tagged object

- `type` (optional)
  Type: string
  
  The type of the tagged object (e.g., commit, tree)

- `url` (optional)
  Type: string, uri
  
  The URL to access the tagged object
