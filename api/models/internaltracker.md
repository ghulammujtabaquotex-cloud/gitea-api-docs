# InternalTracker

Type: InternalTracker

InternalTracker represents settings for internal tracker

Schema: [InternalTracker](https://ghulammujtabaquotex-cloud.github.io/gitea-api-docs/api/models/internaltracker.md)

- `allow_only_contributors_to_track_time` (optional)
  Type: boolean
  
  Let only contributors track time (Built-in issue tracker)

- `enable_issue_dependencies` (optional)
  Type: boolean
  
  Enable dependencies for issues and pull requests (Built-in issue tracker)

- `enable_time_tracker` (optional)
  Type: boolean
  
  Enable time tracking (Built-in issue tracker)
