# Identity

Type: Identity

Identity for a person's identity like an author or committer

Schema: [Identity](https://ghulammujtabaquotex-cloud.github.io/gitea-api-docs/api/models/identity.md)

- `email` (optional)
  Type: string, email
  
  Email is the person's email address

- `name` (optional)
  Type: string
  
  Name is the person's name
