# CommitStats

Type: CommitStats

CommitStats is statistics for a RepoCommit

Schema: [CommitStats](https://ghulammujtabaquotex-cloud.github.io/gitea-api-docs/api/models/commitstats.md)

- `additions` (optional)
  Type: integer, int64
  
  Additions is the number of lines added

- `deletions` (optional)
  Type: integer, int64
  
  Deletions is the number of lines deleted

- `total` (optional)
  Type: integer, int64
  
  Total is the total number of lines changed
