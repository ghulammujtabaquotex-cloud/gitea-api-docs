# PackageFile

Type: PackageFile

PackageFile represents a package file

Schema: [PackageFile](https://ghulammujtabaquotex-cloud.github.io/gitea-api-docs/api/models/packagefile.md)

- `id` (optional)
  Type: integer, int64
  
  The unique identifier of the package file

- `md5` (optional)
  Type: string
  
  The MD5 hash of the package file

- `name` (optional)
  Type: string
  
  The name of the package file

- `sha1` (optional)
  Type: string
  
  The SHA1 hash of the package file

- `sha256` (optional)
  Type: string
  
  The SHA256 hash of the package file

- `sha512` (optional)
  Type: string
  
  The SHA512 hash of the package file

- `size` (optional)
  Type: integer, int64
  
  The size of the package file in bytes
