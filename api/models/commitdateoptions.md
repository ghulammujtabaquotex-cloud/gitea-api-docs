# CommitDateOptions

Type: CommitDateOptions

CommitDateOptions store dates for GIT_AUTHOR_DATE and GIT_COMMITTER_DATE

Schema: [CommitDateOptions](https://ghulammujtabaquotex-cloud.github.io/gitea-api-docs/api/models/commitdateoptions.md)

- `author` (optional)
  Type: string, date-time
  
  Author is the author date for the commit

- `committer` (optional)
  Type: string, date-time
  
  Committer is the committer date for the commit
