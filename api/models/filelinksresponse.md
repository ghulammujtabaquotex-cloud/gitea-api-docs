# FileLinksResponse

Type: FileLinksResponse

FileLinksResponse contains the links for a repo's file

Schema: [FileLinksResponse](https://ghulammujtabaquotex-cloud.github.io/gitea-api-docs/api/models/filelinksresponse.md)

- `git` (optional)
  Type: string
  
  GitURL is the Git API URL for this file

- `html` (optional)
  Type: string
  
  HTMLURL is the web URL for this file

- `self` (optional)
  Type: string
  
  Self is the API URL for this file
