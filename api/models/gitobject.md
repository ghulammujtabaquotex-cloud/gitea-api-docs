# GitObject

Type: GitObject

Schema: [GitObject](https://ghulammujtabaquotex-cloud.github.io/gitea-api-docs/api/models/gitobject.md)

- `sha` (optional)
  Type: string
  
  The SHA hash of the Git object

- `type` (optional)
  Type: string
  
  The type of the Git object (e.g., commit, tag, tree, blob)

- `url` (optional)
  Type: string, uri
  
  The URL to access this Git object
