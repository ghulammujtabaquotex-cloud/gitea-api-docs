# Email

Type: Email

Email an email address belonging to a user

Schema: [Email](https://ghulammujtabaquotex-cloud.github.io/gitea-api-docs/api/models/email.md)

- `email` (optional)
  Type: string, email
  
  The email address

- `primary` (optional)
  Type: boolean
  
  Whether this is the primary email address

- `user_id` (optional)
  Type: integer, int64
  
  The unique identifier of the user who owns this email

- `username` (optional)
  Type: string
  
  username of the user

- `verified` (optional)
  Type: boolean
  
  Whether the email address has been verified
