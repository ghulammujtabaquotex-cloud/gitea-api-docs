# CommitMeta

Type: CommitMeta

Schema: [CommitMeta](https://ghulammujtabaquotex-cloud.github.io/gitea-api-docs/api/models/commitmeta.md)

- `created` (optional)
  Type: string, date-time
  
  Created is the time when the commit was created

- `sha` (optional)
  Type: string
  
  SHA is the commit SHA hash

- `url` (optional)
  Type: string, uri
  
  URL is the API URL for the commit
