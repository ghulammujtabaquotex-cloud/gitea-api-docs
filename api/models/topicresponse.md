# TopicResponse

Type: TopicResponse

TopicResponse for returning topics

Schema: [TopicResponse](https://ghulammujtabaquotex-cloud.github.io/gitea-api-docs/api/models/topicresponse.md)

- `created` (optional)
  Type: string, date-time
  
  The date and time when the topic was created

- `id` (optional)
  Type: integer, int64
  
  The unique identifier of the topic

- `repo_count` (optional)
  Type: integer, int64
  
  The number of repositories using this topic

- `topic_name` (optional)
  Type: string
  
  The name of the topic

- `updated` (optional)
  Type: string, date-time
  
  The date and time when the topic was last updated
