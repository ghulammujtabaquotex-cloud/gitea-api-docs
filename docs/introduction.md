# Gitea API reference

Gitea is a self-hosted Git service written in Go. This site is a
[Sourcey](https://sourcey.com)-generated documentation set built directly from
Gitea's own OpenAPI description, so every endpoint, parameter and schema on the
**API Reference** tab is taken from source rather than retyped.

## The source this site is built from

| Item | Value |
| --- | --- |
| Repository | [go-gitea/gitea](https://github.com/go-gitea/gitea) |

The Gitea API description is generated by Gitea's own tooling from Go source
annotations, then published as `v1-openapi3.generated.json`. Pinning to a tagged
release means the reference matches the code a given Gitea instance runs.

## How to use the reference

- Use the **API Reference** tab and its search to jump straight to an operation,
  request body or response schema.
- Every operation lists its HTTP method, path, parameters, request body and the
  documented responses.
- Authentication is described by seven security schemes in the spec (see
  [Coverage](/coverage/) for the count). In practice you send either an
  `Authorization: token <token>` header or a `token` query parameter.

## What this site does and does not claim

This is a faithful rendering of the upstream spec at the pinned commit. Where
the upstream spec is thin, this site is thin for the same reason and says so on
the [Known gaps](/gaps/) page rather than papering over it.
